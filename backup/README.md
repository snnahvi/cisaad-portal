# WordPress page backups

## publications_wordpress_backup_2026-10-29.html

Backup of the original **Publications** page content on cisaad.umbc.edu
(https://cisaad.umbc.edu/publications/), saved on Oct 29, 2026, before the page
was replaced with the dynamic version (`publications.html`, embedded with an iframe).

This is the page's content as it appears in the WordPress code editor
(the publication list was typed in by hand).

### How to restore the old page
1. Open the Publications page in WordPress and switch to the code view
   (Classic editor: **Text** tab / Block editor: ⋮ menu → **Code editor**).
2. Delete the iframe.
3. Copy everything from `publications_wordpress_backup_2026-10-29.html` and paste it in.
4. Click **Preview** to check, then **Update**.
